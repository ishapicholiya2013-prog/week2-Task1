# Review walkthrough

Show the 760 px media query and reduced-motion setting. Then open app.js: the menu updates aria-expanded and the form combines native validation with trimmed text checks.

The CSS illustration replaces a downloaded photograph. Contact messages are not sent because there is no email backend in this task. Each HTML page has its own title, description and active navigation state.
